# 🖼️ Paperwalls (SANKOU! Walls)

**A high-performance, open-source wallpaper curation engine, lossless image viewer, and desktop styling hub.**

Inspired by Japanese design reference portals (*Sankou*) and *unixporn* desktop aesthetics. Built to serve uncompressed, pristine visuals directly to creators, developers, and customization enthusiasts.

## ✨ Key Features & Capabilities

### 🎨 Visual & Curation Engine
* 🖼️ **8,000+ Curated Wallpapers**: Directly indexes community-driven, high-resolution artwork cataloged from open-source repositories[span_0](start_span)[span_0](end_span).
* 💎 **Lossless Image Quality**: Delivers uncompressed, full-fidelity visuals without aggressive stock image compression or intrusive watermarks.
* 📁 **Categorized Sets & Aesthetics**: Includes organized collections spanning *Set 1: Walls*, *Set 2: Aesthetic*, *Anime*, *Nature*, and *Digital Art*[span_1](start_span)[span_1](end_span)[span_2](start_span)[span_2](end_span).
* 🔍 **Granular Filtering**: Filter artworks by phone aspect ratios, visual themes, aesthetic styling, and popularity metrics[span_3](start_span)[span_3](end_span).

### 💻 User Experience & Local Storage
* 🌗 **Adaptive Dark & Light Themes**: Full UI support for dynamic dark and light mode switching[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).
* 🔖 **Zero-Account Bookmarking**: Save your favorite wallpapers directly into local browser storage for instant access anytime[span_6](start_span)[span_6](end_span).
* 📦 **One-Click Batch Downloads**: Export your entire personal saved collection in a single compressed `.ZIP` file[span_7](start_span)[span_7](end_span).
* 🎬 **Motion & Animation Control**: Dedicated landing screen motion toggles to play or pause background landing animations[span_8](start_span)[span_8](end_span)[span_9](start_span)[span_9](end_span).

### 📑 Deep Image Metadata
* 🎨 **Dominant Color Extraction**: View exact HEX color codes for each wallpaper to match desktop/mobile themes[span_10](start_span)[span_10](end_span).
* 📐 **Technical Specifications**: Inspect full resolution dimensions, file formats, and aspect ratio details[span_11](start_span)[span_11](end_span).
* ✍️ **Creator Attribution**: Built-in credits acknowledging authors and open-source contributors.

## ⚙️ Tech Stack & Architecture

* **UI Framework**: Powered by `aniui` components.
* **Storage Engine**: Client-side IndexedDB / LocalStorage caching for fast response times[span_12](start_span)[span_12](end_span).
* **Image Delivery**: Caching layer designed for high-resolution photo loading without quality degradation.
* **Responsive Layout**: Tailored viewports optimized for mobile, tablet, and desktop environments[span_13](start_span)[span_13](end_span).
